# Chart-Generator
This is a Chart Generator App

Open `index.html` in a browser. The app fills the whole window: settings and data on the left, the chart on the right.

- Chart type, title and unit (shown on the value axis and in tooltips)
- X- and Y-axis labels (bar and line charts)
- A color per data point, editable at any time
- Download as PowerPoint (`.pptx`, with an editable native chart) or as a high-resolution PNG
